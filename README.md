# Proyecto Adquisicion ITM

## Ejecutar el pipeline

Desde la raíz del proyecto, instala las dependencias:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Abre `pipelineProyectoITM.ipynb` en VS Code o Jupyter, selecciona el entorno `.venv` como kernel y ejecuta todas las celdas. Verifica que las fuentes estén en `data/raw/`. Los resultados se guardan en `data/processed/`, `data/integrated/` y `outputs/figures/`.


Ruta fuentes datos crudos: "data/raw"
Ruta fuentes datos procesados: "data/processed"
